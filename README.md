# Simple React App

A simple React product catalogue built with React, TypeScript and Bootstrap.

## Running the application

Clone the repository:

```bash
git clone git@github.com:adrianacm/simple-react-app.git
cd simple-react-app
```

Install dependencies:

```bash
npm install
```

Run application:

```bash
npm run dev
```

Check application here:
http://localhost:5173/

## Assumptions

- Product data is provided by a local JSON file, acting as a mock API.
- Product prices and ratings are assumed to be valid numeric values.
- Filtering by category is based on exact matches.
- Added placeholder images to the data.
